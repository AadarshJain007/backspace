# BACKSPACE

An interactive internet time machine. Travel through different eras of the web and experience how websites, browsers, layouts, and interactions felt at the time.

## Eras

`1995` → `2000` → `2005` → `2010` → `2015` → `2020` → `2026` → `Future`

## Built With

- React
- Vite
- JavaScript & CSS

## Running Locally

```bash
npm install
npm run dev
```

To build for production:

```bash
npm run build
```

## Status

Work in progress — building out the browser shell and each era one step at a time.
